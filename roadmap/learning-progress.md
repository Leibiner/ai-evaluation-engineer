## Evidence Rule

每个能力域至少留下 **1 项可验证证据**；P0 能力必须进入项目。

可接受证据：

- 可运行代码
- Eval Dataset
- Grader
- 自动化测试
- 实验数据
- 指标结果
- Failure Analysis
- Root Cause Analysis
- Regression Case
- Evaluation Report
- 技术设计文档

## 更新规则

1. **不要因为“学过”就打勾。**
2. 实验必须有输入、过程、输出和结论。
3. 代码必须可以运行或被测试验证。
4. 项目证据必须能让第三方复现或审阅。
5. 如果只能描述“会”，但没有证据，保持未完成。
6. 每完成一个模块，更新本文件和对应能力域目录。
