# 《AI 测试进阶课 01｜AI、ML、DL 到底是什么？》

> 第一阶段：AI / ML Foundations
>
> 这篇先不讲复杂算法，只解决一个最基础的问题：**AI、ML、DL 到底是什么，它们之间是什么关系？**

---

## 一、先建立一张地图

第一次系统学习 AI，最容易遇到的问题就是各种名词：AI、ML、DL、神经网络、Transformer……看起来都认识，放在一起却不知道是什么关系。

先记住最简单的一张图：

```text
AI
└── ML
    └── DL
        └── Neural Network
            └── Transformer
```

这不是说它们完全是严格的父子分类，而是帮助我们先建立一个基本的技术层级：**AI 是更大的概念，机器学习是实现 AI 的重要方法，深度学习是机器学习中的一类方法。**

后面的课程再逐步拆开这些概念。

---

## 二、AI 到底是什么？

AI，也就是 Artificial Intelligence，人工智能。

简单理解：

> **让机器完成一些通常需要人进行判断、识别、理解或生成的任务。**

比如：

- 图像识别
- 语音识别
- 推荐系统
- 垃圾信息识别
- 机器翻译
- 文本生成
- 图片生成
- 自动驾驶

所以 AI 本身并不是某一种具体算法。

它更像一个大的目标和技术领域。

而实现这个目标的方法有很多，其中机器学习是非常重要的一种。

---

## 三、什么是 Machine Learning？

先看传统程序。

例如判断一个分数是否及格：

```text
输入：分数
   ↓
程序规则
   ↓
如果分数 >= 60
   ↓
输出：通过
```

这里的规则是程序员写出来的。

程序并不需要“学习”。它只需要按照已经写好的规则执行。

但有些问题很难直接写成规则。

例如：

> 怎么判断一张图片里面是不是一只猫？

你很难把所有情况都写成 if / else。

于是换一种思路：

> **规则不好写，那能不能给机器大量数据，让它从数据中找到规律？**

这就是 Machine Learning，机器学习。

---

## 四、机器到底“学习”了什么？

这里是机器学习最重要的一个认识。

机器学习里的“学习”，不是说机器像人一样理解世界。

更准确地说：

> **模型通过数据和训练过程不断调整内部参数，使自己在某个任务上的预测结果变得更好。**

举一个简单的垃圾短信分类例子。

我们给模型一些历史数据：

```text
短信                         标签

“恭喜中奖100万元”             垃圾
“点击链接领取红包”             垃圾
“今晚一起吃饭吗”              正常
“明天上午10点开会”             正常
```

这些数据组成了 Dataset，也就是数据集。

其中：

```text
Input = “恭喜中奖100万元”
Label = “垃圾”
```

所以可以先建立一个非常重要的概念：

```text
Dataset
   ↓
Input + Label
```

---

## 五、Dataset 是什么？

Dataset 就是用于机器学习的数据集合。

可以简单理解成：

```text
Dataset
├── Sample 1
├── Sample 2
├── Sample 3
├── Sample 4
└── ...
```

每个 Sample 可以包含输入以及对应的信息。

例如垃圾短信任务：

```text
Input：恭喜中奖100万元
Label：垃圾
```

这里需要注意一个非常重要的问题：

**模型学什么，很大程度上取决于它拿到了什么数据。**

如果训练数据本身存在问题，比如：

- 数据数量太少
- 数据不具有代表性
- 数据存在偏差
- 数据质量很差
- Label 标错

那么模型后面学出来的结果也可能存在问题。

所以数据不是 AI 系统之外的东西。

**数据本身就是机器学习系统的重要组成部分。**

---

## 六、Label 是什么？

Label 可以简单理解成：

> **对于当前输入，我们希望模型学习的目标结果。**

例如：

```text
Input：恭喜中奖100万元
Label：垃圾
```

再比如图片分类：

```text
Input：一张猫的图片
Label：猫
```

这里会涉及另一个以后非常重要的词：

**Ground Truth。**

现在先简单理解为：在一个评估或监督学习场景中，我们认为可以作为正确依据的目标答案。

但要注意：

> **Label 并不天然等于绝对正确。**

如果人工标注错了，那么模型学习到的也可能是错误信息。

后面我们会专门学习 Label Quality、Annotation 和 Ground Truth。

---

## 七、Model 到底是什么？

有了数据，还需要一个东西从数据中学习。

这个东西就是 Model，模型。

先不要急着研究复杂的神经网络，可以先把 Model 看成一个可以接收输入并产生输出、内部拥有大量可调整参数的计算系统：

```text
Input
  ↓
Model
  ↓
Output
```

例如：

```text
“恭喜中奖100万元”
        ↓
      Model
        ↓
垃圾：92%
正常：8%
```

模型能够做出这样的判断，是因为它之前经过了训练。

所以现在可以得到：

```text
Dataset
   ↓
Training
   ↓
Model
```

---

## 八、Training 到底是什么？

Training，也就是训练。

简单理解就是：

> **让模型根据训练数据不断调整参数。**

一个非常简化的训练过程可以表示为：

```text
Input + Label
      ↓
    Model
      ↓
 Prediction
      ↓
计算预测结果与目标之间的差异
      ↓
调整参数
      ↓
重新预测
      ↓
不断重复
```

例如一开始模型可能预测：

```text
输入：恭喜中奖100万元

正常：60%
垃圾：40%
```

训练数据中的 Label 是：

```text
垃圾
```

那么模型这次预测就不够好。

训练过程会根据误差信号调整模型参数。

继续训练后，可能变成：

```text
正常：30%
垃圾：70%
```

再继续训练，可能变成：

```text
正常：10%
垃圾：90%
```

这就是我们通常所说的“模型在学习”。

准确来说，是：

> **模型通过训练过程不断调整参数，让预测结果更符合训练目标。**

---

## 九、训练完成以后，模型怎么使用？

训练和使用模型是两个不同的阶段。

训练阶段：

```text
Dataset
   ↓
Training
   ↓
Parameter Update
   ↓
得到训练后的 Model
```

真正使用模型时，我们给它新的输入：

```text
New Input
   ↓
Inference
   ↓
Model
   ↓
Prediction
```

这里的 **Inference** 就是推理，也可以理解成模型训练完成后对输入进行计算并产生结果的过程。

例如：

```text
Input：
“您获得百万大奖，请立即领取”

Inference
   ↓
Model
   ↓
Prediction

垃圾：97%
正常：3%
```

所以目前可以把整个过程串起来：

```text
Dataset
   ↓
Training
   ↓
Model
   ↓
Inference
   ↓
Prediction
```

这条链非常重要，后面学习 AI 时会不断回到这里。

---

## 十、那 Deep Learning 又是什么？

现在再回头看：

```text
AI
└── ML
    └── DL
```

就容易理解了。

Deep Learning，也就是深度学习，是机器学习中的一类方法。

它主要使用多层神经网络来学习数据中的复杂模式。

所以可以先建立这样的关系：

```text
Machine Learning
        │
        └── Deep Learning
                │
                └── Neural Network
```

而现代很多 AI 系统，尤其是大语言模型，其技术基础与深度学习和神经网络密切相关。

后面还会遇到 Transformer。

现在只需要知道：

> **Transformer 是现代深度学习中非常重要的一类网络架构，也是现代 LLM 的重要技术基础。**

具体怎么工作，后面的 LLM Foundations 再学。

第一阶段现在不需要钻进去。

## 十一、为什么模型会出错？

到这里，我们已经知道：

```text
数据
 ↓
训练
 ↓
模型
 ↓
推理
 ↓
预测
```

但是模型并不是永远正确。

例如：

```text
Input：
“这个手机也太好了，卡得我怀疑人生。”

Model Prediction：
正面：70%
负面：30%
```

但实际我们可能认为它应该是负面。

那么问题来了：

> **模型为什么会错？**

原因可能很多：

```text
数据问题
   ↓
Label 问题
   ↓
模型问题
   ↓
训练问题
   ↓
泛化问题
   ↓
数据分布变化
```

所以后面的课程才会继续学习：

```text
Prediction
   ↓
Error
   ↓
Loss
   ↓
Optimization
   ↓
Parameter Update
```

再进一步学习：

```text
Training Set
Validation Set
Test Set
       ↓
Generalization
       ↓
Distribution Shift
       ↓
Data Leakage
```

这些内容共同构成 AI / ML Foundations。

# 十二、第一课到底要记住什么？

如果这一篇只记住一张图，就记住下面这张：

```text
                 AI
                  │
                  ↓
                 ML
                  │
                  ↓
                 DL
                  │
                  ↓
               Model
              ↑     ↓
          Training  Inference
             ↑        ↓
             │    Prediction
             │
          Dataset
          /     \
       Input   Label
```

再记住三句话：

**第一句：**

> AI 是一个大的技术领域，ML 是实现 AI 的重要方法，DL 是 ML 中的一类方法。

**第二句：**

> 机器学习的“学习”，本质上是模型通过数据和训练过程不断调整参数。

**第三句：**

> 模型训练完成后，可以通过 Inference 对新的 Input 产生 Prediction。

这三句话搞清楚，才算真正开始进入 AI 的世界。
