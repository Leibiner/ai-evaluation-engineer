# 07 Safety / Multimodal / Reliability

这是专项能力层，建立在前面的 Evaluation 基础之上。

## Safety / Security

- Jailbreak
- Direct / Indirect Prompt Injection
- Sensitive Data Leakage
- Excessive Agency
- Unsafe Tool Action
- Safety Policy Compliance
- Red Team Evaluation

重点不是收集攻击词，而是建立攻击类别、风险等级、成功判定和回归集。

## Multimodal / Computer Use

- Image Understanding
- OCR：CER / WER 等
- Grounding
- Screen Understanding
- GUI Action
- Computer Use
- Audio / Video Evaluation

## Reliability

- Flakiness
- Timeout / Retry
- Rate Limit
- Dependency Failure
- Degradation
- Recovery
- Availability / Latency
- Version Regression

## 出口

能够针对安全、多模态或可靠性问题定义明确的 Eval Target、Dataset、Grader 和风险指标，而不是停留在人工体验层面。
