# 11 RAG Evaluation

能力地图：11

重点：Retrieval、Recall、Precision、Hit Rate、MRR、NDCG、Context Quality、Faithfulness、Groundedness、Answer Correctness、Answer Relevance。

## 核心原则
Retrieval Failure ≠ Context Quality Failure ≠ Generation Failure ≠ E2E Answer Failure。

## 学习出口
能定位 RAG 失败发生在 Retrieval、Context 还是 Generation。
